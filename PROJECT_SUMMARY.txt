## 🚀 Installation & Running

### Step 1: Install Frontend
```bash
cd client
npm install
```

### Step 2: Install Backend
```bash
cd ../server
npm install
```

### Step 3: Run Frontend
```bash
cd ../client
npm run dev
```
Frontend: http://localhost:5173

### Step 4: Run Backend (New Terminal)
```bash
cd server
npm start
```
Backend: http://localhost:5000
